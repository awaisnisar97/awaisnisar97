## ☁️ ECS Fargate Production Grade Platform

**AWS • ECS Fargate • Terraform • Docker • GitHub Actions • ECR • ALB • ACM • Route 53 • CloudWatch**

Production style containerised application deployed on AWS ECS Fargate.

### Highlights

- 🏗️ Terraform infrastructure using reusable modules
- ☁️ AWS VPC with public and private subnets
- 🐳 Multi stage Docker build
- 📉 Reduced Docker image from **1.66 GB to 92.15 MB**
- 🔐 AWS OIDC authentication with GitHub Actions
- 🔄 CI/CD pipeline using GitHub Actions
- 🛡️ Trivy, Checkov and Gitleaks security scanning
- 🔒 ECS tasks deployed without public IP addresses
- 🌐 Application Load Balancer with HTTPS
- 📜 ACM certificate and Route 53 DNS
- 📊 CloudWatch logging and health checks
- 🏷️ Immutable Docker images tagged using Git commit SHA
- ♻️ Terraform bootstrap layer for infrastructure dependencies
